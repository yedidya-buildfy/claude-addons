# codex-rtl

עברית ב‑Codex בטרמינל מוצגת בכיוון הנכון: הפקודה `codex` נפתחת דרך [dosu](https://github.com/RustNegar/dosu) (רישיון MIT), עטיפת טרמינל דו‑כיוונית.

- כבוי כברירת מחדל. הדלקה: `addons on codex-rtl`.
- ההפעלה הראשונה מתקינה את dosu ב‑Homebrew (`brew install rustnegar/dosu/dosu`). בלי Homebrew, התקנה לפי ההוראות בריפו של dosu.
- אם dosu חסר, `codex` רץ כרגיל.
- קלוד לא עובר דרך dosu: הוא מקווה את הפלט שלו.
- טרמינל חד‑פעמי בלי העטיפה: `command codex`.
- להסרה: `addons off codex-rtl`.

הקוד של dosu לא נכלל בריפו הזה; הוא מותקן מהמקור שלו.
