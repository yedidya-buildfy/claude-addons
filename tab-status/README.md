# נקודה אחת יציבה לכל שיחה

לכל לשונית יש **נקודת מצב אחת בלבד**. כל עוד סוכן כלשהו עובד, מוצג **צהוב בלבד** — גם אם התשובה הראשית הסתיימה, וגם כשפתוחה שאלה או תוכנית לאישור.

| נקודה | משמעות כשאין סוכן פעיל |
|---|---|
| ⚪ | התחלה, מידע לא זמין, או עצירה עקב שגיאה; לא אישור שהעבודה הושלמה |
| 🔴 | השיחה הראשית עובדת |
| 🟣 | השיחה הראשית מכינה תוכנית |
| 🟠 | תוכנית מחכה לאישור |
| 🔵 | שאלה מחכה לתשובה |
| 🟤 | השיחה הראשית פנויה, אבל פקודת רקע עדיין עובדת |
| 🟢 | השיחה הראשית פנויה ואין עבודת רקע ידועה שעדיין פועלת |

צהוב גובר על כל המצבים האחרים. כתום גובר על סגול. אין צירוף של ירוק וצהוב, ואין הוספת עיגול שני.

## מדוע הכותרת יציבה

רק תהליך אחד רשאי לצייר את הכותרת. עדכון הכותרת ומחוון ההתקדמות המובנים של Claude כבויים בהתקנה. התצוגה נבדקת כל חמישית שנייה, אבל **כותרת שלא השתנתה אינה נשלחת שוב**. אם הכתיבה נכשלת, מנסים שוב בלי לסמן בטעות שהעדכון הוצג.

נעילה מונעת שני מציירים באותה שיחה. לפני כל כתיבה נבדק שהלשונית עדיין שייכת לשיחה הזאת; סגירת השיחה או התהליך שלה מפסיקה את המצייר. אין יומן פעימות לב מתמשך.

## איך יודעים שסוכן סיים

המעקב נשען על אישור ההפעלה ועל הודעת סיום המשימה שהמערכת רשמה ביומן השיחה — לא על מספר שחיבור וחיסור עלולים לקלקל. כל סוכן מזוהה בנפרד. סיום כפול לא מוחק סוכן אחר; סיום ישן לא מסיים הפעלה חדשה של אותו סוכן.

עצירה זמנית של סוכן אינה נחשבת סיום: בדיקה נוספת יכולה להחזיר אותו לעבודה. גם ספירת סוכנים ישנה מסוף תור אינה מחליפה מידע חדש. היומן נקרא פעם אחת מתחילתו ולאחר מכן רק מהנקודה שבה הסתיימה הקריאה הקודמת. שורה שעדיין נכתבת נקראת שוב כשהיא שלמה.

ההתאמה נבדקה מול אירועי המשימות של ההתקנה המקומית. אחרי שינוי של מבנה יומן המשימות בגרסה עתידית, יש להריץ שוב את בדיקת הקבלה ולא להסיק מאפס רשומות שאין עבודה.

## שמות אוטומטיים וידניים

נותן השמות האוטומטי נשאר אותו שירות. הוא בוחר שם קצר בשפת ההודעה, ומשאיר שם מתאים ללא שינוי. כשל ברשת משאיר את השם הקיים; אין מסלול נוסף שדורש מהשיחה לשנות שם בעצמה.

תשובה איטית אינה רשאית לדרוס בקשה חדשה, שם שננעץ ידנית, איפוס ידני או שיחה שנסגרה. שמות נשמרים בשלמותם, בלי שלב ביניים שבו התצוגה יכולה לקרוא שם ריק. עיגולי מצב מודבקים ותווי שליטה אינם הופכים לחלק מכותרת הלשונית.

```bash
tn "בדיקת תשלומים"       # שם נעוץ; האוטומציה לא תדרוס אותו
tn --auto "בדיקת תשלומים" # שינוי לא נעוץ; מכבד נעיצה קיימת
tn                       # שחרור הנעיצה וחזרה לשם תיקיית העבודה
```

הפקודה פועלת באותה דרך מתוך הטרמינל ומתוך השיחה. אין להריץ אותה באמצעות Bash או לטעון אותה לתוך המעטפת; מריצים אותה ישירות.

## התקנה ועדכון

```bash
bash install.sh
```

בחרו רק בהתקנת הנקודות אם אין צורך בתוספים אחרים. המתקין מגבה את הקיים, מחליף רק את חיבורי הנקודות שבבעלותו ומשאיר חיבורים והגדרות אחרות. גם פרופיל המודלים החלופי מתעדכן אם הוא כבר קיים, בלי שינוי במודלים. אפשר לאשר החלפה של פקודת שינוי השם הישנה; פקודה מותאמת שאינה הגרסה הישנה המוכרת נשארת ללא שינוי.

**אחרי עדכון, פותחים טרמינל חדש ושיחה חדשה.** שינוי ההגדרות אינו משנה את סביבת ההפעלה של שיחה שכבר רצה, ותהליך תצוגה ישן עשוי עדיין להריץ את הגרסה הקודמת.

אין לשנות שם דרך לחיצה ימנית על הלשונית: שם קבוע של העורך עוקף את הכותרת הדינמית. לשחזור, פותחים את שינוי השם בלחיצה ימנית, מוחקים את הטקסט ומאשרים; לאחר מכן משתמשים בפקודה למעלה.

## בדיקות

```bash
bash tab-status/tab-dots-selftest.sh
# אחרי התקנה:
~/.claude/scripts/tab-dots-selftest.sh
```

הבדיקות יוצרות תיקיות זמניות וטרמינלים פרטיים, לא משנות לשוניות אמיתיות ולא מתקשרות לשירות בחירת השמות. בדיקות המתקין פועלות רק בעותק שבמאגר, שבו המתקין נמצא.

בדיקת קבלה בטרמינל:
1. הפעילו שני סוכנים ובקשו מהשיחה הראשית לענות לפני שסיימו. אמור להישאר צהוב יחיד.
2. תנו לסוכן הראשון לסיים. הצהוב נשאר; ירוק לא מופיע.
3. תנו לאחרון לסיים ולשיחה הראשית לסיים את תגובתה. רק אז מופיע ירוק.
4. הפעילו שוב סוכן שהסתיים, ובדקו חזרה לצהוב; בטלו משימה ובדקו שהצבע משתחרר אחרי אישור הביטול.
5. נעצו שם בעברית, שנו נושא וודאו שהשם לא נדרס. שחררו נעיצה ובדקו שהשם חוזר לשם התיקייה.
6. השאירו את השיחה ללא פעילות: הכותרת נשארת יציבה, בלי הבהובים ובלי שינויי צבע מיותרים.
