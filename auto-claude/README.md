# auto-claude

כל טרמינל חדש נפתח ישר בתוך `claude --dangerously-skip-permissions`.
רוצים טרמינל רגיל? `Ctrl-C` פעמיים — קלוד נסגר ונשארים בשורת פקודה רגילה באותו טרמינל.

לא נפתח ב: shell לא אינטראקטיבי, `zsh -c`, פקודות שקלוד עצמו מריץ, הבדיקה השקטה ש‑VS Code עושה ברקע,
התחברות SSH, ו‑shell שנפתח בתוך טרמינל שכבר התחיל ככה.

טרמינל חד‑פעמי בלי קלוד: `CLAUDE_AUTOSTART_OFF=1 zsh`.
להסרה: למחוק מ‑`~/.zshrc` את הבלוק שמתחיל ב‑`# claude-addons: auto-claude`.

⚠️ המצב הזה מדלג על כל בקשות האישור של קלוד — הוא מריץ פקודות וכותב קבצים בלי לשאול.
