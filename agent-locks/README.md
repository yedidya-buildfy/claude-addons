# agent-locks

כמה סשנים של קלוד קוד באותה תיקייה דורסים אחד את השני בשקט: אחד עורך קובץ
שהשני באמצע לכתוב, ושניים מעלים לאוויר באותה שנייה. התוסף הזה שם שומר לפני כל
כתיבה ולפני כל דחיפה, ואומר בקול מי כבר מחזיק את מה.

**הוא רק מזהיר, אף פעם לא חוסם.** התראת שווא שעוצרת עבודה גרועה יותר מהתראה
שנקראת וממשיכים.

## מה קורה בפועל

| מתי | מה מופיע |
|---|---|
| כתיבה לקובץ שסשן חי אחר מחזיק | "הקובץ בעריכה של סשן אחר (שם), מאז לפני 4 דקות" |
| דחיפה או העלאה בזמן שסשן אחר באמצע | "סשן אחר התחיל העלאה לפני 2 דקות ועדיין באמצע" |
| כל השאר | שקט מוחלט |

התפיסה נרשמת לפי הנתיב המלא של הקובץ, וזה מה שמכוון את התוסף מעצמו: שני סשנים
באותה תיקייה מתנגשים ומקבלים התראה, וסשן שעובד בעותק עבודה משלו לא מתנגש עם
אף אחד — הוא לא נתפס ולא מוזכר. אי־הסימטריה הזאת היא כל הרעיון: הדרך השקטה
לעבוד היא עם עותק משלך.

## שחרור — למה כלום לא נתקע

- ברגע שסשן מסיים תור וממתין למשתמש, כל התפיסות שלו נופלות.
- סשן שקרס או נסגר משתחרר לבד אחרי רבע שעה של שקט.
- אין שום מצב שבו צריך "לשחרר ידנית" כדי להמשיך לעבוד — הכל רק מזהיר.

## פקודות למשתמש

```bash
node ~/.claude/scripts/agent-locks.mjs list    # מי מחזיק מה עכשיו
node ~/.claude/scripts/agent-locks.mjs clear   # לשכוח הכל
```

## מה מותקן

- `~/.claude/scripts/agent-locks.mjs` — כל הלוגיקה, קובץ אחד, בלי תלויות.
- הוקים ב‑`~/.claude/settings.json`: לפני כתיבה לקובץ, לפני דחיפה/העלאה,
  ובסיום תור ובסגירת סשן.
- התפיסות עצמן: קובץ קטן לכל נתיב תחת `~/.claude/agent-locks/`.

## מה זה לא

זה לא נעילה אמיתית ולא תחליף לענפים. סוכן שמחליט להתעלם מההתראה יכתוב לקובץ.
המטרה היא שהמידע יהיה על השולחן ברגע הנכון — לפני הכתיבה, לא אחרי.
