# phone-alerts

התראה לטלפון כשקלוד קוד צריך אותך — שאלה, תוכנית שממתינה לאישור, או סוף עבודה.
עובר דרך [ntfy](https://ntfy.sh): אפליקציה חינמית ל‑iOS/אנדרואיד, בלי חשבון ובלי הרשמה.

## מה מגיע לטלפון

| מתי | איך זה נראה |
|---|---|
| קלוד שואל שאלה או מבקש אישור | ❓ שם‑הפרויקט · שם‑הטאב — נוסח הבקשה |
| תוכנית מוכנה לאישור | 📋 שם‑הפרויקט · שם‑הטאב — "תוכנית מוכנה לאישור" |
| קלוד סיים לעבוד | ✅ שם‑הפרויקט · שם‑הטאב — 180 התווים הראשונים של התשובה |

הכותרת מורכבת משם התיקייה ומשם הטאב (זה שנקבע ע"י `tab-status`), כדי שתדע מי
מבין הסשנים הפתוחים קורא לך. כשהטאב עדיין נושא את שם התיקייה מופיע רק שם אחד.
סוכן שרץ בעץ‑עבודה נפרד היה מציג את המזהה שלו במקום שם — במקרה הזה התוסף מטפס
למאגר שממנו העץ נוצר ומציג את שם הפרויקט האמיתי.

התראות שדורשות התערבות נשלחות בעדיפות גבוהה, ההודעה על סיום בעדיפות רגילה, כך
שאפשר להשתיק את השנייה באפליקציה ולהשאיר רק את הראשונה.

## רק טרמינל שמחכה לך

התוסף מתריע רק כשיש טרמינל שממתין לפעולה שלך. שני מקרים נחסמים בכוונה:

**סוכן שרץ ברקע** מקבל עץ־עבודה משלו ואין לו טרמינל שאליו תחזור. סשן כזה שותק
לגמרי — לא שאלות ולא סיום.

**סיום שהוא לא באמת סיום.** קלוד יכול לסיים תור בזמן שסוכן משנה או פקודת רקע
עדיין רצים; כשהם יחזרו הוא יתעורר וימשיך. במצב הזה אין התראה — היא תגיע בסיום
האמיתי, אחרי שהכל חזר. הבדיקה נעשית מול תמליל השיחה: כל הפעלה של סוכן או פקודת
רקע שעוד לא קיבלה תשובה נחשבת עבודה פתוחה.

**אין התראה על כל סוכן משנה שמסיים** — זה היה רעש.

## התקנה

הרץ את `install.sh` של הריפו ואשר את השלב של `phone-alerts`, ואז פעם אחת:

```bash
~/.claude/scripts/ntfy.sh --setup
```

הפקודה מייצרת לך נושא אקראי פרטי, שומרת אותו ב‑`~/.claude/ntfy-topic` בהרשאות
`600`, ומדפיסה את שם הנושא. נשאר להתקין את אפליקציית ntfy ולהירשם לנושא הזה.
הודעות שנשלחו לפני ההרשמה יופיעו בהיסטוריה, אבל התראה קופצת תקבל רק על חדשות.

בלי הצעד הזה התוסף שותק לגמרי — לא שולח כלום ולא נכשל.

## אזהרת פרטיות — חשוב

נושא ב‑ntfy הוא פומבי. אין סיסמה ואין הרשאות: **כל מי שיודע את שם הנושא קורא את
כל ההתראות שלך**. שתי מסקנות:

1. אל תשתף את הנושא ואל תכניס אותו לגיט. הוא נשמר מחוץ לריפו בכוונה.
2. ההתראה על סיום נושאת את תחילת התשובה של קלוד — כלומר קטעי קוד, שמות לקוחות
   או סודות שהוזכרו שם יוצאים החוצה. השם האקראי הופך ניחוש ללא‑מעשי, אבל למי
   שעובד על קוד רגיש עדיף להריץ שרת ntfy משלו ולהצביע עליו עם
   `CLAUDE_NTFY_SERVER`.

## תור ומרווח

שני סשנים שמסיימים יחד היו נוחתים על המסך כערימה אחת. התוסף מסדר את כל
ההתראות בתור אחד משותף ומרווח ביניהן 5 שניות, כך שהן מגיעות אחת אחרי השנייה.
פרומפט אחד שמפעיל שני מנגנוני התראה בו‑זמנית נחשב לאירוע אחד, והכפילות נזרקת
במקום להצטרף לתור.

## דרישות

`jq` ו‑`curl` (שניהם קיימים ב‑macOS), ואפליקציית ntfy בטלפון.

## הגדרות

| משתנה | ברירת מחדל | מה זה |
|---|---|---|
| `CLAUDE_NTFY_TOPIC` | תוכן `~/.claude/ntfy-topic` | שם הנושא |
| `CLAUDE_NTFY_SERVER` | `https://ntfy.sh` | שרת ntfy חלופי (למשל שרת פרטי) |
| `CLAUDE_NTFY_GAP` | `5` | שניות בין התראה להתראה |

## התקנה ידנית

```bash
cp phone-alerts/ntfy.sh ~/.claude/scripts/ && chmod +x ~/.claude/scripts/ntfy.sh
```

ואז למזג את `phone-alerts/settings.json.snippet` לתוך `~/.claude/settings.json`.

## הסרה

`uninstall.sh` מוחק את הסקריפט ואת ההוקים, ומשאיר את `~/.claude/ntfy-topic`
במקום — כדי שהתקנה חוזרת תמשיך לאותו נושא. למחיקה מלאה יש למחוק אותו ידנית
ולבטל את המנוי באפליקציה.
