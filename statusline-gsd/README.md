# statusline-gsd — ה‑statusline של GSD, מצורף

התיקייה הזו מצרפת את `gsd-statusline.js` מ‑[פרויקט GSD](https://github.com/gsd-build/get-shit-done) כך שסקריפט ההתקנה יכול להשתיל אותו ל‑`~/.claude/` בלי שתצטרך להתקין את כל הפצת GSD המלאה.

**הבסיס אינו הקוד שלי.** זה עותק של GSD בתוספת שינוי מקומי אחד: סגמנט **ניצול תוכנית** (usage). ראו [`ATTRIBUTION.md`](./ATTRIBUTION.md) לקרדיטים ו‑[`LICENSE`](./LICENSE) לרישיון ה‑MIT המקורי.

## מה זה מציג

בתוך ה‑statusline של Claude Code בתחתית כל טרמינל:

```
Fable 5 │ ████░░░░░░ 48% │ ▂▂▅▇▂ 95ms · 76 t/s │ 5h 60% ↻2h07m │ wk 31% · Fable 53%
```

- **מודל** — מודל ה‑Claude הנוכחי. הערת חלון הקונטקסט בשם (`Opus 5 (1M context)`) וגודל החלון מושמטים — מד הקונטקסט שלצידו כבר מדווח אותם
- **אמצע** — משימת ה‑TODO הפעילה כעת, או מצב התכנון של GSD אם נמצא `.planning/STATE.md` כלשהו ב‑workspace שלך, או מושמט
- **מד קונטקסט** — מד התקדמות בן 10 מקטעים שמראה כמה מחלון הקונטקסט ה*שמיש* נוצל. מקודד בצבעים:
  - 🟩 ירוק < 50%
  - 🟨 צהוב 50–65%
  - 🟧 כתום 65–80%
  - 🟥 אדום מהבהב 💀 ≥ 80%
- **מהירות** (תוספת מקומית) — עונה על "המודל איטי או האינטרנט שלי?":
  - `▂▂▅▇▂ 95ms` — זמן הלוך‑ושוב לשרת ה‑API, עם היסטוריית הדגימות האחרונות. כל עמודה נצבעת לפי עצמה: 🟩 <150ms · 🟨 <400ms · 🟥 מעבר לזה. עמודות אדומות מצטברות = הרשת מתדרדרת. הכל ירוק והתשובה זוחלת = המודל עמוס. בלי חיבור: `off`
  - `76 t/s` — קצב הפלט. בזמן שטקסט זורם זו מדידה חיה מהחלון האחרון; בין תשובות זה הקצב של התשובה שהסתיימה, ובאפור אם הוא ישן. `— t/s` = חלון חדש שעוד לא קיבל תשובה
- **ניצול תוכנית** (תוספת מקומית) — אותם נתונים כמו `/usage`:
  - `5h 60% ↻2h07m → 13:16` — ניצול חלון הסשן (5 שעות) + זמן עד איפוס
  - `wk 31%` — ניצול שבועי כולל
  - `Fable 53%` — ניצול שבועי פר‑מודל (מופיע רק כשלמנוי יש מגבלה פר‑מודל)

  אותם ספי צבעים כמו מד הקונטקסט.

### מאיפה נתוני הניצול

- **סשן + שבועי**: מגיעים ישירות ב‑stdin של ה‑statusline (`rate_limits`) — Claude Code מרענן אותם אחרי כל תשובת API. קיים רק במנויי Pro/Max/Team, ורק אחרי התשובה הראשונה בסשן; לפני כן נופל ל‑cache.
- **פר‑מודל**: לא קיים ב‑stdin. הסקריפט `usage-fetch.sh` (מותקן ל‑`~/.claude/scripts/`) שולף את אותו endpoint שבו `/usage` של ה‑CLI משתמש (`api/oauth/usage`, טוקן OAuth מה‑Keychain) וכותב ל‑`~/.claude/cache/claude-usage.json`. ה‑statusline קורא רק את הקובץ, ואם הוא ישן מדקה — משגר את ה‑fetcher ברקע (detached, בלי לחסום רינדור; קובץ lock מונע ריצות כפולות). ה‑endpoint לא מתועד רשמית — אם ישבר, הסגמנט פשוט נעלם והשאר ממשיך לעבוד.

### מאיפה נתוני המהירות

- **זמן תגובה**: תהליך רקע זעיר פותח חיבור TCP ל‑`api.anthropic.com` ומודד כמה זמן לקח. לא נשלחת בקשה ולא עוברים בייטים משלך — רק נתיב הרשת נמדד, ולכן זה קורא ~90ms במקום ~400ms של לחיצת יד מלאה. הוא מודד על השעון של עצמו ולא על הציור של השורה (אחרת המדידה קופאת בדיוק כשהמודל עסוק), רץ אחד בלבד בכל רגע, ויוצא מעצמו חמש דקות אחרי שהשורה הפסיקה להיות מצוירת.
- **קצב פלט**: hook מסוג `MessageDisplay` נורה עם כל אצווה של שורות שהושלמו תוך כדי זרימה, ורושם **אורכים בלבד** — כמה תווים ומתוכם כמה לטיניים. הטקסט עצמו אף פעם לא נשמר. ה‑hook לא מקבל ספירת טוקנים, ולכן ההמרה מכוילת מהתשובות שהשיחה עצמה כבר סיימה: לתשובה בלי קריאת כלי, טוקני הפלט פחות טוקני החשיבה הם בדיוק הטקסט הנראה. מעבר לכך מותאמים שני מקדמים נפרדים לתווים לטיניים ולשאר, כדי שמעבר שפה ייתפס מיד — עברית רצה ~1.45 תווים לטוקן ואנגלית ~3.1, אז מחלק קבוע היה טועה ביותר מפי שניים.

  מאומת מול הספירה של אנתרופיק עצמה על 1,079 חיזויים מוחזקים‑בחוץ: סטייה חציונית 2.0%, אחוזון 90 של 8.8%. אין tokenizer מקומי רשמי לקלוד — רק endpoint ברשת — ומוני צד‑שלישי משתמשים ב‑tokenizer של OpenAI שסופר בחסר.

### כוונון

- `refreshInterval` ב‑`statusLine` שולט בקצב הציור. **המינימום הוא 1 שנייה**, וערך קטן ממנו נדחה בשקט ומשאיר את השורה בלי טיימר בכלל.
- `GSD_NET_SAMPLE_MS` — כל כמה זמן נמדדת הרשת (ברירת מחדל 1000, טווח 1000–300000)
- `GSD_RATE_WINDOW_MS` — חלון המיצוע של קצב הפלט (ברירת מחדל 5000, טווח 1000–30000). חלון רחב מהקצב שבו הטקסט מגיע מחליק את המספר בין פרצים
- קצב הפלט החי דורש `jq`. בלעדיו הכל עובד חוץ מהמדידה החיה

המד לוקח בחשבון את ה‑buffer של ה‑auto-compact ב‑Claude Code (~16.5% כברירת מחדל), אז 100% במד = קונטקסט שמיש מלא (נקודת ההפעלה של ה‑compaction), לא 100% מתקציב הטוקנים הגולמי.

## התקנה ידנית

העתק את `gsd-statusline.js` ל‑`~/.claude/` והפנה אליו את `statusLine` ב‑`~/.claude/settings.json`:

```json
{
  "statusLine": {
    "type": "command",
    "command": "node ~/.claude/gsd-statusline.js"
  }
}
```
